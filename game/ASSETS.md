# Asset provenance

The user supplied these images for this game. Only the required prepacked WebP sheets were copied out of `DLICOM-complete (2).zip`; bundled executable code, historical screenshots, duplicate raw uploads, and Three.js were not imported into the playable app.

Terrain, buildings, crop stages, wildlife, monsters, lighting, UI icons, and map rendering in this build are authored procedurally rather than copied from Harvest Moon. No external font or audio files are requested; sound feedback is generated locally with Web Audio.

The supplied loose character frames have limited directional coverage and some baked-in fragments. The renderer uses selected clean regions/frames and simple directional mirroring rather than claiming a new complete four-direction animation set. Full art-production requirements remain listed in the GDD.
